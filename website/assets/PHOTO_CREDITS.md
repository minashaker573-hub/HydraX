## Updating

Downloaded via `curl` against Unsplash's `images.unsplash.com` CDN with
`w=`/`q=` query parameters to control size and quality at download time —
see the git history for the exact URLs used. To swap an image, find a
replacement under the same free Unsplash License, confirm the page says
"Free to use under the Unsplash License" (not "Unsplash+ License" — that
tier requires a paid subscription and must never be used here), and update
this table.
